## Layout

### Sidebar
- Default width: `220px` (resizable 220–400px)
- Background: `var(--sidebar-bg)` with `backdrop-blur-xl` glassmorphism
- Contains: database selector, tabs/explorer toggle, tab list, footer (archive/spaces/settings)

### Title Bar
- Height: `28px` (`h-7`)
- Drag region for window movement (Tauri frameless)
- Left: sidebar toggle
- Center: window title
- Right: GlobalSearch + window controls

### Query Editor
- Full remaining height split into:
  - **Toolbar** (28px): tab info, format/validate buttons, compact Run button
  - **Monaco Editor** (flex grow): SQL editing with CodeLens
  - **Results Panel** (resizable): query results grid

### Dialog / Modal
- Overlay: `rgba(0,0,0,0.6)` (dark) / `rgba(0,0,0,0.4)` (light)
- Border radius: `rounded-lg` (8px)
- Max width: `w-96` (384px)
- Animation: fade + scale

## Components

### Sidebar Tab Item
- Padding: `px-2 py-1.5 mx-1 my-0.5`
- Active bg: `color-mix(in srgb, ${spaceColor}, transparent 70%)`
- Active strip: 2px left border glow in space color
- Hover: `bg-black/10` (dark) / `bg-white/8` (light)
- Title: 12px, semibold when active
- Subtitle (database): 10px, muted, visible on hover or active

### Toggle Pill (Tabs / Explorer)
- Container: `bg-black/5` (dark: `bg-white/5`), `p-0.5`, `rounded-md`
- Active pill: subtle color bg (`spaceColor` at 10% opacity) + color text
- Icon: 12px lucide icon + label at 10px font-medium

### Run Button
- Icon-only (play triangle)
- Size: `p-1` (20x20px)
- Color: spaceColor bg, white icon
- Disabled: transparent with muted color
- Cancel: red-500 bg

### Database Badge
- Pill shape: `rounded-full`
- Padding: `px-1.5 py-0.5`
- Font: 9px, medium weight
- Connected: green-400 text on green-500/15 bg
- Disconnected: amber-400 text on amber-500/15 bg
- No connection: muted text on bg-hover

### Connection Status Badge (Sidebar)
- Text badge: 9px, medium weight
- "Connected": green-500/20 bg, green-400 text
- "Disconnected": bg-hover bg, muted text

## Animation

### Easing
- Primary: `cubic-bezier(0.4, 0, 0.2, 1)` (expressive ease)
- Drag overlay: `cubic-bezier(0.16, 1, 0.3, 1)` (smooth spring, no bounce)
- Duration: 150–300ms

### Transitions
- Sidebar show/hide: 300ms, `cubic-bezier(0.4,0,0.2,1)`
- Modal entrance: 150ms, fade + zoom-in
- Hover states: 150ms ease
- Tab item active change: 150ms ease-out

### Reduced Motion
- All animations degrade gracefully
- Respects `prefers-reduced-motion: reduce`
- Sidebar uses instant show/hide, no translate animation
- Modals fade without scale

## Iconography

- Library: **Lucide React** (consistent stroke-based icons)
- Size: `w-3 h-3` (12px) for toolbar actions, `w-3.5 h-3.5` (14px) for sidebar items
- Stroke width: 1.5–2px depending on context
- Color inherits from parent text color
